# Security Policy

## Reporting a vulnerability

Please do not disclose security vulnerabilities in a public issue. Instead, use
GitHub's private vulnerability reporting feature under **Security → Advisories →
Report a vulnerability**. Include reproduction steps, affected paths, impact,
and any suggested remediation.

Do not include real credentials, personal information, or production data in a
report. Revoked test credentials should be redacted as well.

## Supported version

Security fixes are applied to the latest commit on the default branch. Older
commits and deployments are not supported.
